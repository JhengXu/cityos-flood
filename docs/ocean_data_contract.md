# 海洋边界数据合同 v0.1

原始观测最低字段：`timestamp, station_id, longitude, latitude, observed_level_m, datum, quality_flag, source`。

- `timestamp` 必须是 ISO 8601 且显式带时区；进入系统后统一为北京时间 `+08:00`。
- `observed_level_m` 单位为米；缺测留空并标记 `missing`，不得用 0 代替。
- `datum` 必填。不同基准面在缺少可追溯换算量时禁止合并或直接比较。
- 分钟级数据按北京时间自然小时取有效样本均值，并保留 `sample_count`。
- 分解结果为 `observed = predicted_tide + surge_residual`，输出观测、天文潮和残差，三者来源必须分别标注。
- 正式调和分析建议至少连续 30 天；代码最低接受 48 个有效小时仅用于管线验证。

深圳地方标准给出的业务岸段映射：深圳湾福田/南山使用赤湾站，珠江口南山/宝安使用深圳临时验潮站，大鹏湾盐田/大鹏使用盐田站，大亚湾大鹏使用惠州站。上述站点目录不代表已取得观测数据。

香港天文台站可作为珠江口邻近参照，但潮高采用香港海图基准。未完成基准面换算前，系统将拒绝与采用 1985 国家高程基准的深圳数据合并。
